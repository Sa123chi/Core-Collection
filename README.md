# Core Collection 🛍️

Core Collection is a single-vertical fashion storefront — considered
clothing, cut to last. Browse the collection, filter by type, pick a
size, and check out (front-end demo — no real payment is processed).

## 🚀 Tech Stack
- React 19 + React Router 7
- Plain CSS (no framework) — custom design system
- Deployed via `gh-pages`

## 📦 Run Locally

1. Clone the repo:
   ```
   git clone https://github.com/Sa123chi/Core-Collection.git
   cd Core-Collection
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the dev server:
   ```
   npm start
   ```
   Opens at http://localhost:3000

4. Build for production:
   ```
   npm run build
   ```

5. Deploy to GitHub Pages:
   ```
   npm run deploy
   ```
